# Mundo Divertido Kids

Jogo Flutter de plataforma com 6 mundos e 3 fases por mundo.

## Áudio
Inclui trilha instrumental infantil original em loop e efeitos sonoros originais para pulo, coleta de moedas, vitória, colisão e cliques. O botão de volume na tela inicial e durante a fase pausa/retoma a trilha e controla os efeitos.

## Gerar APK
Envie o conteúdo deste projeto para a raiz do repositório GitHub e execute o workflow em Actions. O primeiro build baixa as dependências Flutter, incluindo `audioplayers`.
